# ADR-012: Licence

- Status: Accepted
- Date: 2026-11-22

## Context

Share widely, no income, but a reference to the original when used.

## Decision

- Apache-2.0 with a `NOTICE` file: _Based on Gier by Martijn Cornips — https://github.com/cornips/gier_. Redistributions must keep the NOTICE.

## Consequences

Permissive for anyone; attribution is a licence condition, not a request.
